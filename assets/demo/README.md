# Finite personal-review demo assets

`manifest.json` binds 154 exact source/runtime files (588,716,585 bytes) to 155 hydration targets. Every entry records its byte count, SHA-256, retained source path, purpose and targets. `filesSha256` binds the ordered entry list. Approval remains `pending-review`.

The packet includes the 129-file review cache (one manifest and 128 runtime/animation files), nine selected landscape derivatives, two landscape receipts, two path metadata inputs, five original GLBs required by the loaders' provenance checks, the complete 143-original inventory metadata, three existing texture decoder files, and the previously approved Pip/Grandma runtime GLBs with their unchanged manifest. The latter three files close an ambient public-directory dependency; they do not approve the newer review cast. The previous packet manifests are preserved under `output/submitted-before-repair-20260919/packaging-prechange`. Distinct rope forms, character animation sidecars and separate object states retain their individual records. No original, material, animation, transform or image was regenerated or recompressed.

Run `npm run hydrate:demo` to verify and restore declared targets. `npm run verify:demo-assets` verifies every packaged file and every existing target without copying; its `missing` count reports targets that hydration would create. An existing mismatched target causes an error and is preserved. No undeclared file is removed. `npm run build:demo` hydrates automatically, then requires the complete separately tracked authored audio library.

The original files under `output/` remain locally preserved. A clean checkout restores only the five originals needed by this build. The inventory describes all supplied files, including originals outside this finite selection; their presence is not required for ordinary authored demo play. Historical evidence collectors that verify all originals still require the preserved local collection.

The texture worker and Basis transcoder are copied from the existing pinned Three.js 0.186.0 runtime export. See `decoders/THREE-LICENSE.txt`, `decoders/BASIS-README.md` and `decoders/APACHE-2.0.txt` for upstream provenance and license text. The standard Apache text is preserved from the pinned local TypeScript distribution. Meshopt support is bundled from the pinned npm dependency. The `.gitattributes` rule for this directory prevents newline conversion of hash-bound JSON and JavaScript.

`scripts/package-demo-assets.mjs` is a maintainer snapshot command for an already inspected source selection. It verifies the selected files and refuses to replace a differing packaged copy. It is not part of build/start and does not generate assets or grant approvals. Updating the selection requires updating its source bindings and preserving the earlier originals.

`node scripts/verify-demo-package.mjs` creates a fresh isolated directory under `.tmp`, tests hydration and the actual personal loaders, and writes a unique `evidence/demo-release-20260919/package-isolated-*.json` receipt. It also checks rejection of a conflicting target. The previous `verification.json` remains historical evidence. Authored audio has its separate complete verifier in `scripts/verify-demo-audio.mjs`; the isolated packet check makes no audio claim. The isolated copies remain ignored and no live cache is changed. These are filesystem/package checks, not browser, performance, movement or human acceptance.
